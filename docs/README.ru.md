# Документация

**[English](README.md) · [Русский](README.ru.md)**

По странице на концепт; каждая описывает, как ведёт себя выпущенный код, и заканчивается объяснением, почему так. Если вы здесь впервые, начните с [README проекта](../README.ru.md).

## Агенты

- **[Как охранять то, что делает агент](./agents.ru.md)** — вызовы инструментов под политикой человека, отказы, по которым модель исправляется, урезанные права агента, инструменты без таблицы.
- **[Для агентов](./for-agents.ru.md)** — весь API на одной странице, для ассистента, который пишет код на veto.

## Политика

1. **[Объявление ресурсов](./define-abilities.ru.md)** — `defineAbilities`, окружение запроса, ресурсы без строк.
2. **[Правила](./create-rules.ru.md)** — `createRules`: `where`, `fields`, `values`, `when` и хранимая форма JSON.
3. **[Как проверять доступ](./ability.ru.md)** — `buildAbility`, `withEnv`, `onDecision`.

## Условия

- **[Условия](./conditions.ru.md)** — короткая запись, операторы по типу поля, сравнение двух полей, хранимое дерево.
- **[Операторы](./operators.ru.md)** — что каждый отвечает на грязных данных.
- **[Связи](./relations.ru.md)** — условия через связанные ресурсы и их загрузка.

## Применение

- **[Как принимается решение](./rule-evaluation.ru.md)** — запрет побеждает, по умолчанию запрещено, «неизвестно» не разрешает.
- **[Запись](./mutations.ru.md)** — `canMutate` и `validatePayload`.
- **[Фильтрация в базе](./where.ru.md)** — `where()` выбирает ровно то, что разрешает `can()`.
- **[Правила извне](./parse.ru.md)** — `parseRules` на границе доверия.

## В приложении

- **[Гвард](./guard.ru.md)** — `createGuard` для server actions, HTTP-обработчиков и вызовов инструментов.
- **[HTTP-обработчики](./http.ru.md)** — Express, Fastify, Hono.
- **[`@vetojs/react`](./react.ru.md)** — `<Can>`, `useCan`, `useAbility`, серверные компоненты.
- **[Серверный рендеринг](./ssr.ru.md)** — правила через границу и почему статическая страница не несёт вердикта.
- **[`@vetojs/drizzle`](./drizzle.ru.md)** — политика как SQL `WHERE`.
- **[Postgres RLS](./rls.ru.md)** — как работать с обоими и три способа, которыми RLS не защищает ничего.
- **[Переход с CASL](./migrate-from-casl.ru.md)** — соответствие API и отличия в поведении.
