# `@vetojs/next` — переехал

**[English](next.md) · [Русский](next.ru.md)**

> **Пакет снят с поддержки.** Гвард, который в нём лежал, никогда не импортировал ни `next`, ни `react`, поэтому теперь он живёт в движке как [`@vetojs/core/guard`](./guard.ru.md) и точно так же годится для HTTP-обработчиков и вызовов инструментов агентом. `@vetojs/next@0.2.0` остаётся на npm реэкспортом, так что зафиксированная установка продолжит работать, — но здесь он больше не собирается и новых версий не получит.

## Как перейти

Поменять импорт. Больше ничего — API тот же, а пакет, который надо поставить, у вас уже стоит.

```ts
import { createGuard } from "@vetojs/core/guard";
```

После этого уберите `@vetojs/next` из зависимостей. Нужна версия `@vetojs/core` не ниже `0.7.0`.

Всё, что описывала прежняя страница, лежит на [странице гварда](./guard.ru.md) — там же теперь HTTP-обработчики и вызовы инструментов.
